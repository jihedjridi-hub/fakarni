# Fakarni

Location + time reminders: tap a place on a Google Map, draw a circle, get reminded when you arrive.

- **[android/](android/README.md)**: the active app (Kotlin, Jetpack Compose, Google Maps). Built automatically on every push; the APK is on the [latest release](https://github.com/jihedjridi-hub/fakarni/releases/tag/latest).
- **[ios/](ios/README.md)**: paused iOS version (SwiftUI + Google Maps). It compiles; building for a phone needs an Apple Developer account.
